# User Profile Slider

A clean, minimal user profile slider built with vanilla HTML, CSS and JavaScript.
Designed with a Neutral Elegance colour theme inspired by warm creams, 
deep charcoal and antique gold accents.

## Features
- Smooth next / previous navigation with wraparound
- 9 diverse user profiles with real avatars
- Fully responsive card layout
- Google Fonts — Cormorant Garamond & DM Sans
- Zero dependencies — pure HTML, CSS, JS

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)

## How to Run
1. Clone the repo
2. Open `index.html` in your browser
3. That's it — no installs needed
